# Adrian Dias · Música ao vivo

Landing page do músico Adrian Dias (voz, violão e piano) para casamentos, eventos e barzinhos.

Site estático: `index.html` + `assets/`. Publicado pelo GitHub Pages a partir da branch `main`.

## Ajustes rápidos

- **WhatsApp:** em `index.html`, a variável `WHATSAPP` guarda DDI + DDD + número, só dígitos (hoje `5535998102143`). O link do número no bloco de contato também usa esse valor; troque nos dois lugares. Se a variável ficar vazia, o formulário copia a mensagem e abre o direct do Instagram.
- **Fotos e vídeo:** ficam em `assets/`. Para trocar, substitua os arquivos mantendo os nomes.
